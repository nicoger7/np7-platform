## 🚨 CRITICAL BUG: Editions Refactor Broke Queries

The editions refactor moved `date_start`, `date_end`, `price_from`, `price_to`, `deposit`, `max_spots`, `coaches`, etc. from `exp_experiences` to `exp_editions`. But several pages still query `exp_experiences` for those columns.

**These queries will crash (column no longer exists):**

1. **`src/app/experience/page.tsx`** (PUBLIC page)
   - Line 24: `.order("date_start")` on `exp_experiences` — column removed
   - Line 89: `exp.date_start` — no longer on experience
   - Line 110: `exp.price` — this still exists on `exp_experiences` but may not be what you want
   - **Fix:** Join to `exp_editions` to get dates/prices for the current year, or query editions directly

2. **`src/app/experience/[slug]/page.tsx`** (PUBLIC detail page)
   - Lines 111-130: references `experience.date_start`, `experience.date_end`, `experience.price`
   - **Fix:** Fetch the active edition for this experience and use edition dates/prices

3. **`src/app/api/admin/bookings/route.ts`**
   - Line 19: `exp_experiences:experience_id(id, title, slug, location, date_start)` — date_start doesn't exist on exp_experiences anymore
   - **Fix:** Join to `exp_editions` via `edition_id` instead

4. **`src/app/api/admin/bookings/[id]/route.ts`**
   - Line 16: `exp_experiences(title, slug, date_start, date_end)` — both columns removed
   - **Fix:** Join to `exp_editions` via `edition_id`

**The editions table structure:**
```
exp_editions: id, experience_id, year, date_start, date_end, price_from, price_to, deposit, max_spots, spots_taken, status, coaches, experience_code, po_code, pricing_details, payment_page_id, estimated_costs, expected_revenue, expected_profit, expected_variable_costs, paid_revenue, paid_profit, last_synced, active
```

**exp_experiences now only has:** id, title, slug, location, location_lat, location_lng, description, highlights, hero_image, gallery, whats_included, cancellation_policy, status, currency, timezone, hotel, airport_code, whatsapp_group_link, notes, total_fixed_costs, active_status, notion_id

**Bookings have both `experience_id` and `edition_id` columns.** Use `edition_id` to join to `exp_editions` for date/price info.

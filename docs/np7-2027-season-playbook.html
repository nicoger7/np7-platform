03

Bring one experience online — the checklist

The order matters: you can't price a package before the edition exists, or fill the page before there are photos. Everything below is in the admin under np-seven.com/admin.

Create the experience✓ done for all 9

The container for everything. This already exists as a Draft for every 2027 trip — just open it. (For reference: new ones start via Experiences → New, reused ones via Duplicate.)

Admin → Experiences → New (or Duplicate)
  • Title
  • Slug
  • Code
  • Location
  • Airport code
  • Distance from airport
  • Timezone
  • Cancellation policy

Link the spotguide destination✓ done — except Greece & Sept

Every experience points at a Destination — the same place that powers the public Spotguide. Already created & linked for the reuse spots and for Langebaan / Maui / Volosko. Only Greece & September still need one — once you know the spot, create the destination and add at least one place, and the wind graphic fills itself from Open-Meteo.

Admin → Destinations → New → add ≥1 spot
Still to do: Greece & September (decide the spot first)

Add the edition(s) & dates✓ done for reuse trips

An edition is one dated running of the trip. Garda, Alaçatı and Bonaire (all three weeks) already have their 2027 editions — but the dates are last year's +1, so open each and confirm the real dates. The new builds still need their edition added (set travel dates + level band).

Experience detail → Add Edition (or Duplicate)
  • Label (e.g. Week I)
  • Start / end date
  • Level min–max

Hotels & rooms

Add the accommodation and its room types, then set which rooms are available for which week. This is what the booking flow shows and what the packages attach to.

Admin → Hotels  ·  Admin → Hotel Rooms

Components — the priced building blocks

The individual line-items a package is made of: accommodation, coaching, transfer, extras. They're prefixed with the experience code and tied to the edition.

Admin → Components

Packages — what guests actually book

Bundle components into the buyable offers, each with its price and room. Deposit stays 0 (the first invoice is the downpayment) — the payment engine builds the plan from there. Turn on Public website for the ones you want visible.

Admin → Packages
  • Price
  • Deposit = 0
  • Downpayment due (days)
  • Final due (days before)
  • Room link

Coaches & guides

Assign who's coaching this edition from the coach library. They show up on the public page and in the member trip view.

Admin → Event Content → Coaches / Guides

Build the public page (Event Content)

The story people see: hero image (or a looped hero video), tagline, the "About" and "The spot" text, highlights and gallery. Reused spots inherit last year's copy — just adapt the parts that changed.

Admin → Event Content → this experience
  • hero_image
  • hero_video (url·start·end)
  • about
  • location_about
  • highlights
  • gallery

Photos into the media library

This is the long pole — start collecting early. Drop real photos into the experience's media folders; the tiles, heroes and galleries pull from there automatically, and the auto-branded tiles composite the flag & coach on their own.

Experience → Media tab  ·  experiences/<slug>/<category>/

Reviews & trust

Add a few verified guest reviews (from past guests or the trip surveys) — they feed the Crew tab and the trust badges. Reused spots already have theirs.

Admin → Event Content → Reviews

Publish

Flip the experience Status to Active and toggle Public website ON. It's now live-ready. (The season-wide Experience reveal is a separate switch Nico controls — that's the final gate.)

Experience detail → Status: Active + Public website

Walk it like a guest

Open the public page: hero, photos, dates, packages and prices right? Run a test booking through the reserve flow, and check the spot on the map. If it looks great to a stranger, it's done.

04

How to run the season efficiently

Four habits that keep a nine-trip season from becoming nine separate scrambles.

Duplicate before you build

For Garda, Alaçatı, Bonaire and Tenerife, always start from last year's copy. You inherit the page, packages, hotels and coaches — refreshing is minutes, building is hours.

Draft now, publish in batches

Keep everything on Draft while you fill it in. Only flip to Active + Public website once a trip is fully ready — then reveal a batch together, not one dribble at a time.

Chase photos first

Photos are always the bottleneck. Start a shared album per new spot (South Africa, Maui, Croatia, Greece) now — the whole visual identity of the page depends on them.

Finish one, then start the next

Take a new build all the way to "walk it like a guest" before opening the next. Four half-finished pages are worse than one live one.

Start here — your first three moves

The shells are ready. These are the things to do before anything else, in order:

  • Confirm the reuse dates. Open Garda, Alaçatı and Bonaire (×3) and set the real 2027 dates — right now they're last year's +1 and nobody should book against a guess.
  • Start a photo album per new spot. South Africa, Maui and Croatia live or die on their photos, and photos take the longest to gather — begin collecting now, in parallel with everything else.
  • Pin down Greece & September. Both have an experience shell but no spot. Once the location's decided, create its destination (step 2) and the rest of the checklist unlocks.
